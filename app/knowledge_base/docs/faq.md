# AI 项目常见问题

## FastAPI 是什么？

FastAPI 是一个 Python Web 框架，常用于构建 HTTP API。它支持类型提示、请求参数校验和自动生成接口文档。

## 什么是 RAG？

RAG 是检索增强生成。系统先从外部知识库中检索与用户问题相关的内容，再把检索结果交给大语言模型生成回答。

## 什么是 Embedding？

Embedding 是把文本或其他数据转换为向量表示的过程。语义相近的文本通常能够在向量空间中获得较高的相似度。

## 为什么要进行文本切分？

文档可能很长，无法直接全部传给模型。切分可以将文档分成较小的片段，便于检索、控制上下文长度和定位信息来源。
